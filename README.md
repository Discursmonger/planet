# Планета и передвижение по поверхности (Spore / Dyson Sphere Project)

Этот репозиторий — стартовая техническая заметка для реализации «планеты» и передвижения по её поверхности, как в **Spore** и **Dyson Sphere Project**.

## Цель

Сделать:

- сферическую планету;
- локальную гравитацию к центру;
- управление персонажем по поверхности (ходьба, бег, прыжок);
- камеру, которая стабильно следует за персонажем и не «кусает» горизонт.

## Быстрый ориентир

- **Гравитация**: направлена к центру планеты (`-normalize(position)` в локальном пространстве планеты).
- **Ориентация игрока**: `up` персонажа = `normalize(position - planetCenter)`.
- **Движение**: скорость лежит в касательной плоскости, то есть перпендикулярна `up`.

Более детально — в [docs/planet_movement.md](docs/planet_movement.md), включая пример под Unity.
